
# Emmet Nedir ve Ne İşe Yarar?

**Emmet**, HTML ve CSS kodlarını daha hızlı ve kolay yazmamızı sağlayan bir araçtır. Kısa ifadeleri otomatik olarak genişleterek uzun kod bloklarını tek bir kısayolla oluşturmamıza yardımcı olur.

## Ne İşe Yarar?
- HTML etiketlerini hızlıca oluşturur.
- İç içe elementleri kolayca yazmayı sağlar.
- Tekrarlanan kodları otomatik oluşturur.
- CSS özelliklerini daha kısa ifadelerle yazmayı sağlar.
- Kod yazma süresini azaltarak verimliliği artırır.

## Örnek Kullanım

Emmet ile şu ifadeyi yazabiliriz:

```html
ul>li*3
```

Emmet bu ifadeyi aşağıdaki HTML koduna dönüştürür:

```html
<ul>
  <li></li>
  <li></li>
  <li></li>
</ul>
```

## Nasıl Kullanılır?

Emmet, Visual Studio Code gibi birçok kod editöründe yerleşik olarak bulunur. Desteklenen bir dosyada kısaltmayı yazıp genellikle `Tab` tuşuna basarak kodu genişletebilirsin.

## Sonuç

Emmet, özellikle HTML ve CSS öğrenenler ve web geliştiricileri için kod yazmayı hızlandıran, pratik ve kullanışlı bir araçtır.
